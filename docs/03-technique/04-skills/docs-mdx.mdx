Ce skill fournit les règles et la procédure pour rédiger, enrichir et publier des fiches documentaires interactives sur le portail **Zudoku** (`docs/`).

---

## 1. Quand l'utiliser

- Création ou mise à jour de fiches documentaires dans `docs/`.
- Intégration de diagrammes Mermaid (`sequenceDiagram`, `flowchart`, `erDiagram`, `mindmap`).
- Régénération de l'arborescence et des redirections via `scripts/docs/generate-navigation.mjs`.
- Résolution d'erreurs de compilation Zudoku ou d'hydratation MDX.

---

## 2. Informations à lire

- Configuration Zudoku : `docs/zudoku.config.tsx`.
- Script de génération de navigation : `scripts/docs/generate-navigation.mjs`.
- Fichier de navigation généré : `docs/zudoku.navigation.tsx`.
- Thème CSS Zudoku : `docs/zudoku.theme.css`.

---

## 3. Procédure Pas à Pas

### Étape 1 : Structurer le fichier MDX

- Créer le fichier avec l'extension `.mdx` dans le sous-dossier thématique approprié (ex: `docs/03-technique/03-fonctionnalites/04-ma-fiche.mdx`, avec un en-tête `title`, `sidebar_label` et `description`).
- Inclure obligatoirement le frontmatter YAML :
  ```yaml
  ---
  title: Titre Explicite de la Fiche
  description: Description concise d'une phrase pour le sommaire et les métadonnées.
  ---
  ```

### Étape 2 : Syntaxe MDX & Règles de Formatage

- ⚠️ **Règle absolue :** Ne pas insérer de blocs HTML imbriqués avec des sauts de ligne vides non échappés pour éviter les avertissements d'hydratation React.
- **Diagrammes Mermaid :** Utiliser le composant `<Mermaid>` (les blocs de code `mermaid` ne sont pas rendus par Zudoku) :
  ```mdx
  <Mermaid
  	title="Titre du schéma"
  	chart={`flowchart LR
      A[Client] --> B[Serveur Next.js]
      B --> C[(Fichiers de contenu)]`}
  />
  ```
- **Mathématiques & Notations :** Utiliser KaTeX inline `$x$` ou en bloc `$$...$$` si nécessaire.
- **Accents français :** Toujours renseigner les accents français sur les textes lisibles par l'humain (É, È, À, Ç, etc.).

### Étape 3 : Régénérer la navigation et valider la compilation

Après toute création, renommage ou suppression de fichier MDX :

```bash
# 1. Régénérer docs/zudoku.navigation.tsx avec les nouvelles fiches
pnpm docs:nav

# 2. Compiler et vérifier le pré-rendu statique
pnpm docs:build
```

---

## 4. Livrable & Vérification

- Fichier `.mdx` créé ou mis à jour avec des liens internes valides et un sommaire clair.
- Commande `pnpm docs:build` validée avec **0 erreur et 0 avertissement**.
- La nouvelle page apparaît dans la barre latérale sous sa catégorie avec son libellé formaté.
