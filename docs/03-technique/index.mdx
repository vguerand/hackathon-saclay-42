Ce dépôt contient **le site du hackathon** (Next.js 16 en export statique, React 19, Mantine v7) et **cette documentation** (Zudoku, dossier `docs/`).

Le site n'a **ni serveur applicatif, ni base de données, ni compte utilisateur**. Tout le contenu est dans le dépôt, et tout ce qui demande une saisie passe par des formulaires Tally gérés par 42 Paris.
